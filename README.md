# RAVEN T-Shirt Store

A static GitHub Pages website for a RAVEN T-shirt company. It includes a storefront, local login/signup, cart, checkout, customer account page, and admin panel for adding or editing products.

## Upload To GitHub Pages

Upload these files to a GitHub repository:

- `index.html`
- `styles.css`
- `app.js`

Then go to `Settings` > `Pages`, choose `Deploy from a branch`, select your main branch and `/root`, then save.

## Important

This is a free static hosting version, so data is saved in browser local storage. It is good for demos, small manual stores, and testing. For real customer accounts and secure admin access, you will eventually need a backend database.
